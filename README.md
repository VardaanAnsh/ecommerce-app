# E-Commerce Backend App

This is a backend project for an e-commerce website built using Node.js and Express.js.

## Features

- User login and signup with JWT
- Product listing and details
- Add to cart and manage cart
- Admin can add products
- MongoDB used as database

## Tech Stack

- Node.js
- Express.js
- MongoDB
- EJS for server-side pages

## How to Run

1. Clone the repo:
